## 📌 Giới thiệu
Bài thực hành giúp sinh viên rèn luyện kỹ năng thiết kế bài trình chiếu bằng **Microsoft PowerPoint**, bao gồm:

✨ Slide Master  
✨ Animation  
✨ Action  
✨ Custom Slide Show

## 🖌️ Bài thực hành 1 – Thiết kế cơ bản

| Nội dung | Mô tả |
|---------|------|
| 🎨 Định dạng Slide Master | Tạo bố cục thống nhất |
| 📝 Tạo slide theo mẫu | Thiết kế nội dung chuẩn |
| 🔄 Transition & Animation | Hiệu ứng chuyển và động |
| 🔗 Liên kết & hành động | Điều hướng giữa các slide |
| ▶️ Custom Slide Show | Tạo 2 phương án trình chiếu |
